# ShortList 1.0.0

The first public release of **ShortList**: a free, open-source, self-hostable job tracker that updates itself from your email and job portals. Built for Indian job seekers (Naukri, LPA, notice period), and works everywhere.

**[Try the live demo](https://yash-satankar.github.io/shortlist/demo.html)** (fictional data, read-only; it may take a minute to wake up) · **[Website and docs](https://yash-satankar.github.io/shortlist/)** · **[Self-host it](https://yash-satankar.github.io/shortlist/docs/self-hosting.html)**

## Highlights

- **Capture in one tap**: share a job from the LinkedIn or Naukri app on Android (installable PWA), or save it from any job page with the Chrome extension, job description included. Spreadsheet import with a dry run.
- **Updates itself**: job emails (read-only IMAP, every 5 minutes) and your applications list on job portals move statuses forward. A portal's "application sent" email for a job you don't track creates it. Every automatic change follows one set of rules: forward only, offers always reviewed, unsure signals wait for you, everything undoable.
- **Follow up on time**: one inbox for changes to review, follow-ups due and possible ghosting, with email and LinkedIn drafts you send yourself.
- **Prepare and ask**: interview prep packs from the JD and your resume, and "Ask my job search" (counts come exactly from your data; other answers cite your records). AI is optional: bring your own key (Anthropic, Groq, Together or any OpenAI-compatible endpoint), with a monthly cap.
- **Yours**: self-host with one command, export everything, delete your account anytime. Salaries, contacts, emails and AI keys are encrypted at rest.

## Install

**The app (self-hosted):**

```bash
git clone https://github.com/Yash-Satankar/shortlist.git && cd shortlist
cp .env.example .env   # set ENCRYPTION_KEYS and APP_ORIGIN
docker compose --profile app up -d
```

Open it and the first-run screen creates your admin account. To run it for free, see [free hosting](https://yash-satankar.github.io/shortlist/docs/free-hosting.html) (an Oracle Cloud Always Free VM, or Render + Neon).

**The Chrome extension** (not on the Chrome Web Store yet):

1. Download `shortlist-extension-1.0.0.zip` below and unzip it into a folder you'll keep.
2. Open `chrome://extensions`, switch on **Developer mode**, click **Load unpacked** and choose the folder.
3. Open ShortList from the toolbar, enter your ShortList's address, then pair it from Settings → Browser extension.

## Requirements

- Docker with Compose (or Node 22+ and PostgreSQL 15+ with `pg_trgm`)
- HTTPS in front of the app outside `localhost` (any reverse proxy; the docs use Caddy)
- Optional: an AI provider key, a mailbox for email updates, SMTP for password reset

## Notes

- Everything is optional and can be switched off, per server (`FEATURE_*` in `.env`) and per user (Settings → Features). [`.env.example`](https://github.com/Yash-Satankar/shortlist/blob/main/.env.example) documents every variable.
- Migrations run automatically on start. Back up first when you upgrade: [upgrading](https://yash-satankar.github.io/shortlist/docs/UPGRADING.html).
- Full list of changes: [CHANGELOG.md](https://github.com/Yash-Satankar/shortlist/blob/main/CHANGELOG.md).
